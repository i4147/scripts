## Deliverable

## Requirements
1. Use `argparse`. Expose every behavioral difference between the original
   scripts as a CLI argument.
   - Use subcommands if the scripts are distinct modes/jobs.
   - Use flags if they are variations of one pipeline.
2. Factor shared logic (imports, helpers, config, error handling) into common
   functions. Do NOT duplicate code.

4. Move hardcoded values (paths, constants, magic numbers) into CLI args, with
   defaults equal to the original values.
5. If differences cannot be unified, keep BOTH behind a flag/choice. Never
   silently pick one.
6. Sensible defaults so it runs out of the box. Print help if ambiguous.
7. Type hints on all public functions. Docstrings on all public functions and

8. Standard library only, unless the originals already import third-party

## Output format (exactly these three sections, in order)
### 1. Comparison table
Markdown table: script name | what it does | shared with others | unique to it |

### 2. Merged script

### 3. Mapping

    original_name2.py  ->  python merged.py mode-b --flag ...

- Keep the module-level docstring (with usage examples).
